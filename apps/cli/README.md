# Scaffold Forge

> Forge your stack. One command.

Scaffold Forge is an enterprise-grade, composable CLI for generating layered project architectures. It resolves dependencies deterministically and supports deep-merge configurations out of the box, ensuring zero configuration conflicts.

## 🚀 Installation

Install the CLI globally via NPM:

```bash
npm install -g scaffold-forge
```

## 🛠 Usage

### Interactive Mode
Generate a new project by answering a series of prompts to build your custom stack:

```bash
sfg forge my-enterprise-api
```

### Headless / CI/CD Mode
For automated pipelines, bypass the interactive prompts using environment variables:

```bash
SFG_NON_INTERACTIVE=true \
SFG_FRAMEWORK=express \
SFG_ORM=prisma \
SFG_LANGUAGE=typescript \
sfg forge my-automated-api
```

## 🏗 Generated Architecture

Projects generated by Scaffold Forge are not just boilerplate; they are production-ready architectures featuring:
- **Deterministic Deep-Merge:** `package.json` dependencies and scripts from Base, Framework, and ORM layers are mathematically merged without overrides.
- **Provenance Lockfile:** A `sfg.lock.json` file is generated to track the exact configuration hash and fragment versions used, enabling safe future migrations.
- **Zero-Trust Plugin System:** Extensible lifecycle hooks for third-party integrations (e.g., Docker, CI/CD pipelines, Auth providers).

## 📚 Advanced Usage & Plugins

Scaffold Forge supports a plugin architecture. You can extend the generation process by injecting plugins that listen to `afterWrite` hooks to scaffold Dockerfiles, GitHub Actions, or JWT configurations.
